# Rotor-Blade-Airfoil-Performance-Analysis-using-BEMT
Implemented Blade Element Momentum Theory (BEMT) in Python to evaluate rotor blade aerodynamic performance across candidate airfoil profiles, solving the nonlinear inflow equation iteratively at each blade station using the Newton–Raphson method. Computed thrust coefficient (C_T), power coefficient (C_P), and Figure of Merit (FM) as functions of collective pitch angle, generating performance maps to identify optimal pitch settings and maximum aerodynamic efficiency. Results directly informed airfoil selection for the swashplateless micro-helicopter rotor design.
